Submission Exporter for LeetCode

Back up your own LeetCode code as a ZIP, in your browser. No cookie copying, no server.

Pick what to export

  • All submissions: wrong attempts too, oldest to newest
  • Accepted only: every accepted submission
  • Latest accepted per problem: one file per solved problem

You also get an ORDER.csv that lists every submission in the order you made it.

Install

Firefox Add-ons Chrome / Edge (GitHub)

Chrome and Edge: download chrome.zip, unzip, then chrome://extensions → Developer mode → Load unpacked.

Private by design

It runs only on leetcode.com in your own logged-in tab and builds the ZIP on your device. Nothing is uploaded. Read the privacy policy.
